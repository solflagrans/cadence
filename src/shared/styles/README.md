# Дизайн Priority

Основа — спокойные списки и типографическая иерархия Things, осознанное
планирование Sunsama. Светлая тема: тёплый нейтральный фон, белые поверхности,
графитовый текст и приглушённый зелёный акцент.

`tokens.css` — единственный источник общих визуальных значений. Он подключён
из `app/globals.css`; CSS Modules используют переменные без повторного импорта.
Новые общие значения добавляем сюда, а не дублируем в компонентах.

## Правила использования

- Цвета выбираем по назначению: `background` для страницы, `surface` для
  поверхности, `foreground` для основного текста, `text-secondary` для пояснений,
  `text-muted` для метаданных. Последний не предназначен для текста на акценте.
- `border` — декоративные разделители; `border-control` — границы полей.
  Акцентные кнопки используют `on-accent`, выбранные элементы — `on-selected`.
  Для ошибок есть `danger`, для опасных кнопок — `on-danger` и состояния наведения
  и нажатия. Цвет статуса всегда дополняется текстом или значком.
- Отступы — шкала `space-*` с шагом 4px при стандартном размере шрифта.
  Внутри формы обычно 16px, между разделами 24–32px. Значение 2px используется
  только для небольших оптических поправок.
- Основной текст — `font-size-body`, подписи — `small`, метаданные — `caption`.
  Заголовок страницы — `title` с `line-height-tight` и `letter-spacing-heading`.
  Для сопоставляемых чисел используем `font-variant-numeric: tabular-nums`.
- Кнопки и поля имеют минимальную высоту `size-control` (44px), а не фиксированную:
  текст при увеличении масштаба должен помещаться. Иконка может быть 20px,
  но её интерактивная область должна оставаться не меньше 44px.
- Скругления выбираем по роли: `control`, `card`, `dialog`; `pill` — для меток.
  Обычным строкам и карточкам тени не нужны. Тени предназначены для всплывающих
  элементов и диалогов.
- Основная область ограничивается `layout-content-width`, форма —
  `layout-form-width`. Внешние поля — `layout-page-gutter`.
- Адаптивный переход к компактной навигации: `@media (max-width: 48rem)`.
  CSS-переменные нельзя использовать в условиях media queries, поэтому этот
  порог задаём буквально; дополнительные пороги вводим только по необходимости.
- Уровни наложения — `z-*`. Всплывающие элементы внутри диалога располагаются
  выше него; модальные элементы должны корректно блокировать фон и управлять фокусом.
- Анимируем только нужные свойства (например, цвет и прозрачность), используя
  `duration-*` и `easing-standard`; `transition: all` не используем.
  При reduced motion длительности обнуляются. Непрерывные анимации требуют
  отдельного отключения в компоненте.
- Общий видимый фокус уже задан в `globals.css`; не убираем его без равноценной
  замены. Disabled-состояние дополняем настоящей семантикой disabled/aria-disabled.

Структурные значения (`0`, `100%`, `auto`, `1fr`) допустимы непосредственно
в CSS. Общие цвета, интервалы, радиусы и тени берём из токенов.

## Пример CSS Module

```css
.panel {
  padding: var(--space-6);
  color: var(--color-foreground);
  background: var(--color-surface);
  border: var(--border-width) solid var(--color-border);
  border-radius: var(--radius-card);
}
```

Визуальные проверки выполняет пользователь. Агент не запускает браузерные
проверки и не корректирует внешний вид по собственной визуальной оценке.
